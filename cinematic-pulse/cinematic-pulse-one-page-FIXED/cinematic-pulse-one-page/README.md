# Cinematic Pulse — One Page Version

This package combines the four supplied Stitch pages into one single-page website.

Tabs:
- Home
- Movies
- TV Shows
- My List

The visual content, movie/show cards, typography, icons, and image references from the supplied pages are preserved. Navigation switches the four page sections without loading another HTML page.

## Run
Open `index.html` with VS Code Live Server.

## Important
The supplied Stitch HTML uses externally hosted Google/Stitch image URLs and Google Fonts/Material Symbols. Those image URLs are preserved exactly, so an internet connection is required for those remote images/fonts to load.

The `assets/screens/` folder contains the screenshots that were included in the original ZIP.
