# Cinematic Pulse (HTML + CSS + JS)

Structure:
- index.html            markup only
- css/styles.css        custom CSS (moved from inline <style> blocks)
- js/tailwind-config.js Tailwind theme config (unchanged)
- js/main.js            all page scripts, merged in original order
- assets/screens/       original images
- DESIGN.md             design tokens

Run: open index.html with VS Code Live Server.
Internet is needed for the Tailwind CDN, Google Fonts, Material Symbols icons and the remote movie posters.
