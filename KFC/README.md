# KFC App — One Page HTML/CSS/JS

A KFC-inspired food ordering UI based on the requested four-tab workflow:

1. Home
2. Menu
3. Cart / Order
4. Profile & Orders

## Run
Open `index.html` with VS Code Live Server. Internet is required for the hosted food images and Google Font.

## Tech
HTML5, CSS3, Vanilla JavaScript, localStorage for the demo cart.
