CREX one-page website  (HTML + CSS + JS)
=========================================
Open index.html in a browser - that's it.

index.html            markup only (same structure, text, classes, images as the original)
css/style.css         all styling (Tailwind compiled with the ORIGINAL config + original inline styles)
js/main.js            all behaviour (tabs, innings switch, player search, smooth anchor scroll)
tailwind.config.js    original theme config, kept for reference (colors, fonts, spacing)
download_assets.py    optional: run once with internet to store images + fonts locally (offline site)

Images and fonts load from their original hosted URLs (Google) until you run download_assets.py.
